# The Forgotten Pillar Notes

An open-source, wiki-style collection of Bible study notes, Spirit of Prophecy research, and Seventh-day Adventist history. Built with [Quartz](https://quartz.jzhao.xyz) and written in [Obsidian](https://obsidian.md)-flavored Markdown.

**[notes.forgottenpillar.com](https://notes.forgottenpillar.com)**

## Features

- Interconnected notes with forward links, backlinks, and a visual graph
- Full-text search
- Push notifications for new notes
- Installable as a Progressive Web App (PWA)
- Audio narration on select notes (powered by ElevenLabs)
- Print-ready / save as PDF
- Reading mode for distraction-free study

## Project Structure

All notes live as Markdown files in the [`content/`](content) folder, organized by topic:

- `doctrine/` — Doctrinal studies
- `sda-history/` — Seventh-day Adventist history
- `sanctification/` — Sanctification and practical Christianity
- `pattern-matching-gospel/` — Gospel patterns in the Old Testament
- `miscellaneous/` — Other topics
- `poetry/` — Poetry

## Contributing

Contributions are welcome — new notes, improvements to existing ones, or bug fixes. See the [Contribution Guide](https://notes.forgottenpillar.com/contribute) for details.

The quickest way to contribute: every note on the site has an **edit** button that takes you directly to the GitHub editor.
