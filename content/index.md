These Wiki style notes are an *experimental* part of my note-taking process (*work-in-progress forever*), where I extract and organize data during my studies. I use the [Obsidian App](https://obsidian.md/) for taking notes and conducting research, and these public notes is a subset of my research notes.

My goal is to create high information density wiki style notes for my future forgetful self, in a sharable format. My hopes are that someone else might find my aggregation of the data useful in his/her own personal research. There are several key features these note pages will be beneficial for you:

- **forward links** - notes are linked with each other. One piece of data is linked with another, so whenever one piece of data is connected with another, I will do my best to link these notes
- **backlinks** - every note contains also a list of backlinks showing notes which are mentioning the current. Very useful for traversing the though line backwards.
- **search** - when you remember that you read some note somewhere, yet you did not remember exactly the path, with fuzzy search you can try get back to the right chain of thoughts
- **tags** - if you are looking for a topic, notes are also annotated with the tags

I hope you find these resources useful too.
Blessings,
